# Support

> ⚠️ **`ax-ros2-ref` is an experimental reference implementation — not an Axelera
> product.** It is provided **as-is**, with **no service-level agreement (SLA)**, no
> warranty, and **no guarantee of support, maintenance, or bug fixes** from Axelera AI.
> Any assistance is offered on a **best-effort basis only**.

Please read this before asking for help.

## What "best-effort" means

- There is **no SLA** and **no committed response or resolution time**. Questions and pull
  requests may be answered slowly, or not at all.
- This project is **not covered by any Axelera commercial support contract or product
  warranty**. Having Axelera hardware or a Voyager SDK license does **not** entitle you to
  support for this repository.
- APIs, packages, launch files, and behavior **may change or break without notice**.
- Maintainers may close issues or pull requests that are out of scope for a reference
  implementation, without further action.

Use this project as a **starting point and reference** for your own integration — not as
production code you expect to be supported.

## Getting help

Before asking for help:

1. **Read the documentation** — start with the [README](README.md) and the guides in
   [`docs/`](docs/), especially [`docs/quickstart.md`](docs/quickstart.md) for setup and
   troubleshooting.
2. **Search the [Axelera developer community](https://community.axelera.ai/)** to see if
   your question has already been answered.

If you still need help, please use the appropriate channel below.

## Where to ask

**For bugs, questions, ideas, and usage help with this reference implementation, please
post on the [Axelera developer community](https://community.axelera.ai/).** Include a
clear description, steps to reproduce, relevant logs, and your environment (OS, ROS2
distribution, Voyager SDK version, Metis hardware, and any robot hardware in use) so
others can help you effectively.

| Topic | Where |
| :--- | :--- |
| Bugs and reproducible defects in this repo | [Axelera developer community](https://community.axelera.ai/) |
| Questions, ideas, and usage help for this repo | [Axelera developer community](https://community.axelera.ai/) |
| Security vulnerabilities | **Do not** post publicly — see [Reporting security issues](CONTRIBUTING.md#reporting-security-issues) |
| Axelera **product / hardware / Voyager SDK** questions | [Axelera developer community](https://community.axelera.ai/) and [Axelera Support Portal](https://support.axelera.ai) |

## Contributing fixes

Because support is best-effort, the fastest way to get a problem solved is often to suggest a fix yourself and open a pull request. Contributions are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
